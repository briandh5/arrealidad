# Mira AR

App #8 del reto 101 apps de Brian Hawkins. Landing de una propuesta de realidad aumentada para el ecosistema de Google: señalas un edificio con la cámara y aparece la ficha del lugar con reseñas, cómo llegar, sitio web y compra de boletos.

- Hero con video (Chicago, Lakefront Trail) y ficha estilo Google Maps encima del edificio seleccionado.
- Secciones: restaurantes, cines y fotos al instante.
- Contacto de Brian al final, con enlaces a LinkedIn y al reto 101 apps.

## Correr

```bash
npm install
npm run dev        # desarrollo
npm run build      # producción (Vercel la detecta como Vite)
npm run artifact   # un solo HTML para la vista previa
```

Stack: Vite + React 19 + Tailwind 3 + Lucide.
